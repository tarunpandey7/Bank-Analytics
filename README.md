# Banking Analytics & Dashboard Projects

This repository contains end-to-end **banking analytics projects** developed using **SQL, Power BI, Tableau, and Microsoft Excel**. The projects focus on analyzing **bank loan data** and **debit/credit transaction data** to derive actionable business insights and present them through interactive dashboards.

---

## 📌 Project Overview

The goal of this repository is to demonstrate the complete data analytics workflow:
- Data extraction and transformation using SQL  
- Data cleaning and preparation  
- KPI calculation and trend analysis  
- Interactive dashboard creation for business decision-making  

---

## 📊 Projects Included

### 1️⃣ Bank Loan Analysis
- Analysis of loan applications, approvals, and repayments  
- Identification of loan performance trends and risk factors  
- Dashboards created using **Power BI, Tableau, and Excel**

### 2️⃣ Debit & Credit Transaction Analysis
- Analysis of debit and credit transaction behavior  
- Customer spending patterns and transaction trends  
- Interactive dashboards for financial monitoring  

---

## 🛠️ Tools & Technologies

- **SQL** – Data querying, joins, aggregations, and analysis  
- **Power BI** – Interactive dashboards with KPIs, filters, and slicers  
- **Tableau** – Visual analytics and drill-down dashboards  
- **Microsoft Excel** – Data cleaning, pivot tables, and summary reports  

---

## 📁 Repository Structure

- `*.sql` – SQL queries used for analysis  
- `*.pbix` – Power BI dashboard files  
- `*.twbx` – Tableau dashboard files  
- `*.xlsx` – Excel datasets and reports
